🐶 Dogs

Uma rede social para amantes de cachorros, desenvolvida com React.

🚀 Projeto

O Dogs é uma aplicação web desenvolvida durante o **Curso de React da Origamid**, com o objetivo de colocar em prática conceitos fundamentais e avançados do desenvolvimento de aplicações React.

Durante o desenvolvimento, foram aplicados conceitos como componentes, Hooks, Context API, gerenciamento de estado, requisições a API, autenticação de usuários e roteamento.

Além dos conceitos apresentados no curso, o projeto recebeu ajustes e melhorias durante o desenvolvimento, incluindo configurações necessárias para publicação e funcionamento em produção na Vercel.

✨ Funcionalidades

- Cadastro de usuários
- Login e autenticação
- Recuperação de senha
- Publicação de fotos
- Feed de publicações
- Visualização individual das fotos
- Comentários nas publicações
- Exclusão de fotos
- Perfil do usuário
- Estatísticas do usuário
- Navegação entre páginas
- Validação de formulários
- Tratamento de erros
- Layout responsivo

⚙️ Como executar o projeto

Pré-requisitos

- Node.js
- npm
- Git

Clone o repositório

```bash
git clone https://github.com/diegoandradelr/dogs.git
```

Acesse a pasta do projeto

```bash
cd dogs
```

Instale as dependências

```bash
npm install
```

Execute o projeto

```bash
npm run dev
```

Após iniciar o projeto, o Vite exibirá no terminal o endereço local para acessar a aplicação.

📦 Build para produção

```bash
npm run build
```

☁️ Deploy

A aplicação foi publicada utilizando a **Vercel**, com integração ao repositório do GitHub para facilitar o processo de deploy.

Também foi configurado o roteamento da aplicação para garantir o funcionamento correto das rotas do React Router em produção.
